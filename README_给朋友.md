# 给朋友的 K/60 使用说明

这个项目把一份日频价格表变成三套可检查的 Kelly 回测：

- 日频：看过去 60 日，计算下一日仓位；
- 周频：看过去 60 周，计算下一周仓位；
- 月频：看过去 60 月，计算下一月仓位。

它会告诉你方向判断准确率、策略收益、买入持有收益、最大回撤和换手，并画出净值曲线。它是研究工具，不会承诺盈利，也不会自动替你交易。

## 最快体验

需要 Python 3.11 或更高版本，不需要安装其他 Python 包。

macOS / Linux：

```bash
git clone https://github.com/charlesyzk/kelly-mvp.git
cd kelly-mvp
python3 run_web.py
```

Windows：

```powershell
git clone https://github.com/charlesyzk/kelly-mvp.git
cd kelly-mvp
py run_web.py
```

浏览器打开：

```text
http://127.0.0.1:8765
```

然后有两种体验方式：

1. 点击“载入合成演示”，快速确认页面和计算正常；
2. 上传仓库中的 `test/DEXUSEU_FRED.csv`，使用真实公开汇率数据测试。

点击“开始计算”后，页面会出现日、周、月三张结果卡和三条净值曲线。结束时回到运行窗口按 `Ctrl+C`。

## 使用自己的数据

准备 UTF-8 CSV，必须有三列：

```csv
date,symbol,adjusted_close
2020-01-02,NVIDIA,5.97
2020-01-03,NVIDIA,5.90
2020-01-06,NVIDIA,5.93
```

- `date`：`YYYY-MM-DD`；
- `symbol`：标的名称，同一文件可以放多个标的；
- `adjusted_close`：有限且大于零的复权收盘价。

为了得到月频结果，最好准备至少六年以上的日线数据。每个标的同一天只能有一条记录。

## 页面上的设置

- `Kelly 比例`：默认 0.5，即使用 Full Kelly 的一半；
- `单边成本`：按照仓位变化量扣除，10 bps 等于 0.10%；
- 仓位边界固定为 −100% 到 +100%。

参数不要反复试到历史结果最好看。先用开发段修改策略，确定规则后再看保留段；如果看过保留段又继续修改，它就不再是未见数据。

## 它究竟怎么算

Kelly 必须有一个对未来收益分布的估计，但 Kelly 自己不会预测分布。本项目这样估计：

1. 每个时点只取此前 60 个同频率收益；
2. 计算这 60 个收益的一至四阶矩；
3. 暂时假设下一期仍具有相同的前四阶矩；
4. 用四阶公式求出边界内的 Full Kelly 仓位；
5. 乘以页面设置的 Kelly 比例；
6. 用下一期真实收益验证方向和盈亏。

因此页面数字都是后端逐期计算的，不是写死的。唯一的合成内容是明确标为 `SYNTHETIC_DEMO` 的演示行情。

## 怎么读结果

- 方向准确率高，不等于收益一定高；仓位大小同样重要。
- 策略盈利，不等于跑赢买入持有。
- 全区间表现好，不等于未来还能保持。
- 测试数据的结果只证明程序能运行，不证明模型可实盘。

如需核对每一次计算，点击“下载逐期明细 CSV”；里面有窗口日期、四个矩、Full Kelly、实际仓位、下一期收益、成本和累计净值。

## 常见问题

网页打不开：确认运行窗口仍显示 `Kelly MVP is running`，且没有关闭终端。

没有月频结果：数据长度不足；60 个月收益还需要下一月来验证，建议提供至少六年以上日线。

端口被占用：

```bash
python3 run_web.py --port 8877
```

然后打开 `http://127.0.0.1:8877`。
