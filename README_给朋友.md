# 给朋友的 K/60 使用说明

这个项目把一份日频价格表变成三套可检查的 Kelly 回测：

- 日频：看过去 60 日，计算下一日仓位；
- 周频：看过去 60 周，计算下一周仓位；
- 月频：看过去 60 月，计算下一月仓位。

它会告诉你方向判断准确率、策略收益、买入持有收益、最大回撤和换手，并画出净值曲线。它是研究工具，不会承诺盈利，也不会自动替你交易。

## 最快体验

需要 Python 3.11 或更高版本，不需要安装其他 Python 包。

macOS / Linux：

```bash
git clone https://github.com/charlesyzk/kelly-mvp.git
cd kelly-mvp
python3 run_web.py
```

Windows：

```powershell
git clone https://github.com/charlesyzk/kelly-mvp.git
cd kelly-mvp
py run_web.py
```

如果使用 Windows CMD 或 Anaconda Prompt 配置 EODHD，应使用：

```bat
set "EODHD_API_TOKEN=你的Token"
py run_web.py
```

`export` 只适用于 macOS、Linux、WSL 或 Git Bash。

浏览器打开：

```text
http://127.0.0.1:8765
```

然后有三种体验方式：

1. 点击“载入合成演示”，快速确认页面和计算正常；
2. 上传仓库中的 `test/DEXUSEU_FRED.csv`，使用真实公开汇率数据测试。
3. 如果已经购买 EODHD，在网页中直接填写股票代码和日期，下载真实行情后计算。

点击“开始计算”后，页面会出现日、周、月三张结果卡和三条净值曲线。结束时回到运行窗口按 `Ctrl+C`。

结果下方的“仓位与调仓轨迹”可以切换日频、周频和月频：

- 目标仓位曲线：零线上方表示做多、下方表示做空；
- 单次调仓变化：显示目标仓位每次向多或向空方向改变了多少；
- 模拟逐笔调仓：显示开多、开空、加仓、减仓、平仓和反手，支持分页查看；
- 下载调仓流水 CSV：导出全部频率的完整调仓记录。
- 下载仓位信号 CSV：包含最新一个尚无未来收益的“待验证”仓位。

这些记录由相邻两期目标仓位直接相减产生，是真实回测计算结果，但不是券商成交单。项目没有成交股数和具体执行价格，因此不会假装某笔委托已经在市场成交。

## 使用已经购买的 EODHD

Token 只配置在运行网页的电脑上，不要写进代码或发到微信群。macOS / Linux：

```bash
export EODHD_API_TOKEN="你的Token"
python3 run_web.py
```

Windows PowerShell：

```powershell
$env:EODHD_API_TOKEN="你的Token"
py run_web.py
```

打开网页后：

1. 选择“EODHD 取数”；
2. 输入代码，例如中国深交所 `300308.SHE`、美股 `AAPL.US`；
3. 设置开始日期，结束日期可留空；
4. 点击“拉取真实日线”；
5. 页面确认返回条数后，再点击“开始计算”。

接口只负责取得日频复权价格。项目会在本机把它转换成统一格式，并自行生成周线、月线后进行 Kelly 回测。每次拉取会使用 EODHD API 额度；是否能取得某个市场和历史区间由购买的套餐决定。

## 使用自己的数据

准备 UTF-8 CSV，必须有三列：

```csv
date,symbol,adjusted_close
2020-01-02,NVIDIA,5.97
2020-01-03,NVIDIA,5.90
2020-01-06,NVIDIA,5.93
```

- `date`：`YYYY-MM-DD`；
- `symbol`：标的名称，同一文件可以放多个标的；
- `adjusted_close`：有限且大于零的复权收盘价。

为了得到月频结果，最好准备至少六年以上的日线数据。每个标的同一天只能有一条记录。

## 页面上的设置

- `Kelly 比例`：默认 0.5，即使用 Full Kelly 的一半；
- `单边成本`：按照仓位变化量扣除，10 bps 等于 0.10%；
- 仓位边界固定为 −100% 到 +100%。

参数不要反复试到历史结果最好看。先用开发段修改策略，确定规则后再看保留段；如果看过保留段又继续修改，它就不再是未见数据。

## 2026-09-05 改进报告评审与改动记录

我们评审了一份《高阶矩动态 Kelly 策略》设计报告。结论是：报告适合当研究参考，但不适合整份照搬。它会把当前的单策略工具重新扩展成六模型研究平台，让使用者再次面对模型、窗口和收益口径的大量选择。这与本项目“做减法、保留一条可检查主线”的目标冲突。

本次已经采纳并实现：

- 保留 `M4_SIMPLE` 作为唯一正式交易模型；
- 增加未限制 RAW Kelly、有界 M4 解、求解位置和触界比例；
- 增加“经验精确 Kelly”，用来检查 M4 四阶近似与未截断经验目标之间的误差，但不用它交易；
- 增加扣除已配置交易成本后的单期和年化对数增长；
- 保留最新一个尚无未来收益的窗口，标记为 `pending` 待验证信号；
- 新增 `signals.csv` 和网页诊断区，可查看当前仓位、调仓状态和近似误差。

以下内容没有照搬：

| 报告建议 | 本次决定 | 通俗原因 |
|---|---|---|
| 六个模型并行 | 暂不加入 | 模型越多，越容易在历史数据中挑中“看起来最好”的偶然结果，使用者也会再次失去边界。 |
| 日/周/月改用 252/104/60 期 | 继续统一使用 60 期 | 不同窗口同时改变了观察长度和覆盖时间，会分不清结果究竟是频率造成的，还是窗口造成的。 |
| 立即加入无风险利率 | 暂缓 | 必须先确定数据源、利率期限、可获得日期、频率换算和缺失值处理，否则可能引入前视偏差或错算绝对财富。 |
| FDR、多模型显著性检验 | 暂缓 | 现在只有一个正式策略，还没有需要校正的多重假设检验族。 |
| 普通 Bootstrap 置信区间 | 暂缓 | 金融数据前后有联系，随机打乱重抽样可能得到过于乐观的区间，需要另外设计时间序列区块抽样。 |
| 经验精确 Kelly 直接下单 | 只作诊断 | 它只是把过去 60 期样本当成一个经验分布，“精确”不等于掌握了真实未来分布。 |
| 按 `clip(Kelly比例 × RAW)` 转换仓位 | 保留当前规则 | 两种写法在 RAW 超界时会得到很不同的仓位，不能不说明就改变风险。 |
| 暂不计算交易成本 | 不采用 | 项目已经按仓位变化扣除可配置单边成本，删掉只会让结果更乐观。 |
| 暂不做完整复利 | 不采用 | 项目已经逐期复利并计算净值和回撤，不应该退回简单累加收益。 |

还有两个口径修正：

1. 前四阶矩不是“完整分布”。不同的分布可以有相同的前四阶矩，但尾部风险完全不同。
2. 如果加入现金的无风险收益率 `r_f`，风险资产普通收益率为 `R`，风险仓位为 `f`，绝对财富倍数应为：

```text
M = (1-f)(1+r_f) + f(1+R)
  = 1+r_f+f(R-r_f)
```

只写 `1+f(R-r_f)` 会省略现金本身的收益，或者只能解释为一种近似的相对收益口径。在无风险数据契约定义清楚前，本项目不会用它替换现有收益公式。

一个最能看出风险差异的例子：RAW Kelly 等于 `4`、Kelly 比例等于 `0.5`、仓位边界为 `[-1,1]` 时：

- 报告倾向的 `clip(0.5 × 4)` 得到最终仓位 `1`；
- 当前项目的 `0.5 × clip(4)` 得到最终仓位 `0.5`。

前者是 100% 仓位，后者是 50% 仓位。本次保留后者，因为它与已经对外说明的现有规则一致，也更保守。如果未来要改，必须先明确 `[-1,1]` 究竟是 Full Kelly 的求解边界，还是最终实盘仓位边界。

## 它究竟怎么算

Kelly 必须有一个对未来收益分布的估计，但 Kelly 自己不会预测分布。本项目这样估计：

1. 每个时点只取此前 60 个同频率收益；
2. 计算这 60 个收益的一至四阶矩；
3. 暂时假设下一期仍具有相同的前四阶矩；
4. 用四阶公式求出边界内的 Full Kelly 仓位；
5. 乘以页面设置的 Kelly 比例；
6. 用下一期真实收益验证方向和盈亏。

因此页面数字都是后端逐期计算的，不是写死的。唯一的合成内容是明确标为 `SYNTHETIC_DEMO` 的演示行情。

页面还会用同样的60期样本计算一次“不作四阶截断”的经验精确 Kelly，帮助判断四阶近似误差。它只作为检查项，不改变实际下单仓位。最新一期没有未来收益时会显示“待验证”，不会提前算入准确率和收益。

## 怎么读结果

- 方向准确率高，不等于收益一定高；仓位大小同样重要。
- 策略盈利，不等于跑赢买入持有。
- 全区间表现好，不等于未来还能保持。
- 测试数据的结果只证明程序能运行，不证明模型可实盘。

如需核对每一次计算，点击“下载逐期明细 CSV”；里面有窗口日期、四个矩、Full Kelly、上期与本期仓位、仓位变动、下一期收益、成本和累计净值。只想查看发生变化的调仓，则下载“调仓流水 CSV”。

## 常见问题

网页打不开：确认运行窗口仍显示 `Kelly MVP is running`，且没有关闭终端。

没有月频结果：数据长度不足；60 个月收益还需要下一月来验证，建议提供至少六年以上日线。

端口被占用：

```bash
python3 run_web.py --port 8877
```

然后打开 `http://127.0.0.1:8877`。
