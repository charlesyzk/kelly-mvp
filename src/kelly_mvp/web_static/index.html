记录仓位变化

Δf = 本期目标仓位 − 上期目标仓位

每次非零 Δf 形成一条模拟调仓记录，并按统一单边成本计算。

方向准确率只统计有方向的时期；若财富归零，单期对数增长显示为空而非伪造有限值。最新一期没有未来收益时保留为“待验证”。
