# 《高阶矩动态 Kelly 策略》改进报告评审

评审对象：`higher_moment_kelly_strategy_design.html`。本文件记录取舍，不把外部报告直接当成项目需求。

## 总结

报告的数学框架大体自洽，也包含若干应补入当前项目的审计能力；但它描述的是旧版“六模型研究平台”，不能整体替代当前已经确定的单模型、统一 60 期 MVP。直接照搬会重新引入范围膨胀，并改变已经对用户说明过的策略定义。

## 逐项结论

| 报告主张 | 结论 | 理由与处理 |
|---|---|---|
| Kelly 是仓位配置而非涨跌预测 | 接受 | 与当前口径一致。准确率是描述指标，收益和对数增长分别报告。 |
| `M4_SIMPLE` 四阶目标 | 接受 | 与当前实现公式一致，仍是唯一交易模型。 |
| 经验精确 Kelly | 有条件接受 | 仅用作同窗口诊断基准，衡量 Taylor 截断导致的仓位差和目标损失；不参与交易。 |
| 平均单期对数增长 | 接受 | 它与 Kelly 目标直接对应；按扣除已配置交易成本后的净财富倍数计算。 |
| 保留最后一个无未来收益的窗口 | 接受 | 作为 `pending` 当前信号输出，不进入任何样本外绩效。 |
| 方向成功率 | 部分接受 | 保留为用户关注的描述指标；零仓位和零收益都没有可判定方向，不进入分母。 |
| 保留 RAW、边界解和最终仓位 | 部分接受 | 增加未约束 RAW 与边界位置诊断；实际交易规则仍保持“有界最优 × Kelly 比例”。 |
| 六种模型并行 | 不接受为当前改动 | 违背做减法目标，也会让使用者重新面对模型选择问题。 |
| 日/周/月窗口改成 252/104/60 | 不接受为当前改动 | 与用户明确的统一前 60 期问题冲突；如果要比较窗口，应另立预注册实验。 |
| 引入无风险超额收益 | 暂缓 | 理论上合理，但报告没有定义数据源、发布日期、频率复利、缺失值和绝对财富口径，直接加入会制造新的前视与口径风险。 |
| FDR、置信区间和多模型显著性体系 | 暂缓 | 当前只有一个正式策略；在没有预先定义候选族前引入多重检验没有对象。 |
| 暂不计算成本和完整复利 | 不适用 | 当前项目已经逐期复利，并按仓位变化扣除可配置单边成本，不能倒退删除。 |

## 三个重要校正

1. 一至四阶矩不是“完整分布”。当前 M4 只使用四个经验原始矩；经验精确诊断才使用窗口中的全部样本点，但它仍只是经验分布，不是真实未来分布。
2. 报告的 `1+fZ` 是相对无风险资产的财富倍数。如果需要报告绝对财富，尚需乘以同期无风险财富因子；因此在无风险数据契约确定前不能直接替换当前收益。
3. 报告的仓位转换文字与当前实现不同：报告倾向于 `clip(λ×RAW)`，当前是 `λ×BOUNDED`。原始解超界时二者差异很大。本轮保留当前规则，并输出 RAW 供后续单独决策。

## 本轮实施范围

- 增加 `raw_kelly`、求解位置和触界率；
- 增加同窗口 `exact_full_kelly`、平均绝对仓位差和方向一致率；
- 增加扣费后平均单期/年化对数增长；
- 新增 `signals.csv`，保留最新 `pending` 信号；
- 网页显示诊断指标，并在仓位曲线和调仓表中标出待验证信号。

明确没有改动：正式交易模型、统一 60 期窗口、Half Kelly 规则、仓位边界和交易成本公式。

若某期扣费后财富倍数不大于零，`log(M)` 在有限实数中无定义；该期对数增长输出为空，年化几何增长记为 `-100%`，不使用人为截断值。
